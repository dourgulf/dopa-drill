# 多巴练习

[日本語](README.md) | [简体中文](README.zh-CN.md)

多巴练习是一款在浏览器中运行的算术练习游戏。每解答一道题，画面效果和音乐都会逐渐热闹起来。

吉祥物“多巴吉”会搬运输入的数字，并在答对时庆祝。随着答题进度推进，画面和声音越来越丰富，最后如同一场庆典。答错也不会降低气氛，更不会游戏结束。

## 特点

- 涵盖小学一至六年级的 58 项计算技能（依据日本学习指导要领），包括加减乘除、竖式中间步骤、小数、分数和百分比等。
- “我的水平”模式从水平测试开始，根据掌握情况逐步解锁技能。
- 提供按年级练习、单项练习、错题复习和技能树。
- 答对全部基础题可得 100 分。首次正确率达到 80% 后，可在限时加练中争取更高分数。
- 音乐和音效均使用 Web Audio API 合成，无需音频文件。
- 支持手机竖屏和电脑；电脑上可使用数字键和 Backspace 输入。
- 可在设置中调整动态效果强度或关闭声音。
- 记录保存在设备的 localStorage 中，不会发送到外部。
- 支持日语和简体中文，可在设置中切换；语言选择保存在设备上。

## 本地运行

无需构建，静态托管 `app/` 即可：

```bash
python3 -m http.server 8000 -d app
```

在浏览器中打开 `http://localhost:8000/`。项目使用 ES Modules，请通过 HTTP 访问，直接用 `file://` 打开无法正常运行。

## 测试

使用 Node.js 20 或更高版本运行：

```bash
node --test tests/*.test.mjs
```

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `app/` | 游戏主体，使用无第三方依赖的 ES Modules |
| `app/js/locales/` | 各语言的显示文本 |
| `docs/SPEC.md` | 产品规格 |
| `docs/curriculum.md` | 年级课程和技能树设计 |
| `docs/dopakichi.svg` | 多巴吉的造型参考 |
| `tests/` | 单元测试 |
| `tools/build_fonts.sh` | 重新生成字体子集的工具，添加界面文字后运行 |
